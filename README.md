# Roadmap Kotlin

# Roadmap Kotlin + Android + Backend (Versão Melhorada)

## Objetivo Final

Ao concluir este roadmap você será capaz de:

- Desenvolver aplicativos Android profissionais
- Criar APIs REST com Kotlin
- Trabalhar com banco de dados
- Utilizar arquitetura moderna
- Criar um portfólio competitivo
- Estar preparado para vagas de Desenvolvedor Android Júnior/Pleno
